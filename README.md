# Python-length-converter

A simple commandline application that converts centimetres to inches.

Features

1. Accepts decimal measurements
2. Validates user input
3. Rejects zero and negative measurements
4. Handles invalid input using exception handling
5. Allows the user to exit by entering "Q"
6. Displays conversion results to four decimal places

  CONCEPTS PRACTICED

1. while loops
2. User input and type conversion
3. Conditional statements
4. "try" and "except"
5. Raising exceptions with "ValueError"
6. String methods: ".upper()" and ".strip()"
7. F-strings and numeric formatting
8. Loop control using "break"

  CONVERSION FORMULA 

Inches = Centimetres ÷ 2.54
